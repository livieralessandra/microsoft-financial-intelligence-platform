# Decision Framework

This framework defines the questions the product is designed to support. It is
not evidence that user research has already confirmed every outcome.

After using this platform, users should be able to answer:

1. Is Microsoft performing well overall?

2. What is driving Microsoft's financial performance?

3. What changed compared to previous periods?

4. Are there any risks or opportunities I should pay attention to?

5. What should I investigate next?

6. Can I confidently explain Microsoft's business performance to someone else?

The financial dashboard currently supports questions 1, 3, 4, 5, and 6 through
validated current, quarterly, and annual analytics. Question 2 is supported for
FY2026 Q4 through the approved business-driver packet. Other periods must not
receive inferred qualitative drivers when an approved packet is unavailable.

The framework supports business understanding, not buy/sell decisions,
valuation, forecasts, or investment advice.
